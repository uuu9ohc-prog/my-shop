## 3. 확정 사항

- 페이지 흐름: 시작 로딩 → 첫 화면 → 디자인 선택 → 커스텀 → 완성 로딩 → 완성 페이지 → 주문 완료
- 시작 로딩: 사이트에 처음 들어오면 털실이 소복이 쌓이는 로딩 화면
- 완성 로딩: 방문자가 고른 털실이 뽑히면서 최종 완성본으로 넘어감
- 디자인: 강아지·고양이·토끼·곰·코끼리·호랑이 총 6가지
- 색상: 빨강·분홍·주황·노랑·초록·파랑·남색·검정·회색·흰색 총 10가지, 약간 파스텔 톤
- 털실: 부슬부슬한 털실·벨벳형 부드러운 털실·두툼한 털실 총 3가지
- 크기: 10cm / 20cm / 30cm (높이 기준)
- 커스텀: 색상·털실·크기를 한 페이지에서 선택. 색 3부위·털실·크기를 모두 골라야 완성하기로 넘어가며, 빠진 항목이 있으면 막고 어느 항목을 고르지 않았는지 알려 줌
- 선택값: 주문 전에 되돌아갈 때(다시 꾸미기, 이전)는 고른 값을 유지하고, 주문 완료 후 '처음으로'를 누르면 초기화
- 디자인 선택: 별도 페이지
- 주문 확인: ~~별도 페이지~~ → 두지 않음. 완성 페이지의 주문하기가 바로 주문 완료로 이동 (2026-11-26)
- 첫 화면: 브랜드 인상을 전하는 별도 화면. 참고 사진(MODOA 메인 페이지) 레이아웃 기준으로 브랜드 문구 "한 땀 한 땀, 소중한 인형을 위하여"(사이트 전체 통일) → 디자인 둘러보기(6종 카드 슬라이드) → 만드는 순서 안내 → 인테리어·실제 사용 예시 → 푸터
- 주문 완료: 결제 입력·주문 확인 화면 없이 주문하기 다음에 바로 완료 화면을 보여줌 (실제 결제 없음). '처음으로' 버튼으로 첫 화면에 돌아감

## 4. 고른 대안과 이유

| 항목 | 고른 대안 | 이유 |
|---|---|---|
| A. 커스텀 단계 구성 | 한 페이지에 색상·털실·크기 섹션 배치 | PC 우선이라 넓은 화면에 미리보기를 띄워 둔 채 선택지를 옆에 둘 수 있음 |
| B. 디자인 선택 위치 | 별도 페이지로 분리 | 디자인을 고르는 일과 꾸미는 일이 나뉘어 흐름이 명확함 |
| C. 주문 확인 방식 | ~~별도 페이지~~ → 없음 (2026-11-26) | 가격·제작 기간이 아직 미정이라 확인할 내용이 없고, 주문 단계를 하나 줄임 |
| D. 첫 화면 | 브랜드 인상을 전하는 별도 첫 화면 | '따뜻하고 포근한 손맛'이라는 인상을 전달하기에 유리함 |
| E. 주문 마무리 | 결제 화면 대신 주문 완료 화면 | 실제 결제가 없으므로 입력 단계를 줄이고 완료 안내로 마무리 |

## 5. 추후 결정

- 첫 화면 대표 이미지
- 첫 화면 인테리어·실제 사용 예시에 쓸 사진

- 크기·털실별 가격 금액
- 제작 기간
- 저장·공유 이후의 다음 행동
- 시작 로딩(털실이 쌓임)과 완성 로딩(고른 털실이 뽑힘)을 이어지는 연출로 할지 여부
