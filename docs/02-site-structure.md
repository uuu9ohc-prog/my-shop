## 1. 페이지 흐름

0. 시작 로딩 → 1. 첫 화면 → 2. 디자인 선택 → 3. 커스텀 → 4. 완성 로딩 → 5. 완성 페이지 → 6. 주문 확인 → 7. 주문 완료

## 2. 방문자 행동별 구성

| 방문자 행동 | 필요한 정보·기능 | 배치할 페이지 / 섹션 | 다음 행동 |
|---|---|---|---|
| 사이트에 처음 들어온다 | 털실이 소복이 쌓이는 로딩 연출 | 0. 시작 로딩 | 첫 화면 보기 |
| 브랜드 인상을 느낀다 | 따뜻하고 포근한 손맛을 전하는 화면 — 브랜드 문구 "한 땀 한 땀, 당신을 위하여", 대표 이미지(추후 결정), 만드는 순서 안내 | 1. 첫 화면 | 디자인 고르기 |
| 공간에 놓인 모습을 떠올린다 | 인형 인테리어·실제 사용 예시 이미지 6장 | 1. 첫 화면 – 인테리어 예시 섹션 | 디자인 고르기 |
| 인형 디자인을 고른다 | 디자인 6가지: 강아지·고양이·토끼·곰·코끼리·호랑이 | 2. 디자인 선택 | 커스텀 시작 |
| 3군데의 색을 고른다 | 약간 파스텔 톤의 색상 10가지 (빨강·분홍·주황·노랑·초록·파랑·남색·검정·회색·흰색), 디자인별 3부위 (부위 추후 결정), 누르면 바로 반영되는 미리보기 | 3. 커스텀 – 색상 섹션 | 털실 고르기 |
| 털실을 고른다 | 털실 3종 (부슬부슬한 털실·벨벳형 부드러운 털실·두툼한 털실) 선택, 누르면 털실별 설명 표시 | 3. 커스텀 – 털실 섹션 | 크기 고르기 |
| 크기를 고른다 | 10cm / 20cm / 30cm 선택 (치수 기준 추후 결정) | 3. 커스텀 – 크기 섹션 | 완성본 보기 |
| 완성을 기다린다 | 방문자가 고른 털실이 뽑히는 로딩 연출 | 4. 완성 로딩 | 최종 이미지 확인 |
| 완성된 인형을 확인한다 | 고른 색과 털실 느낌이 반영된 최종 이미지, 선택 요약, 주문하기 버튼 | 5. 완성 페이지 | 주문하기 |
| 완성 인형을 저장·공유한다 **[가정]** | 저장·공유 기능 **[가정]** | 5. 완성 페이지 위 레이어 | 추후 결정 |
| 가격과 제작 기간을 확인한다 | 크기·털실에 따라 달라지는 가격 (금액 추후 결정), 제작 기간 (추후 결정), 확인 버튼 | 6. 주문 확인 | 확인 → 주문 완료 |
| 주문 완료를 확인한다 | 주문 요약, 완료 안내 문구, 털실 연출 이미지 (실제 결제 없음) | 7. 주문 완료 | 추후 결정 |

## 3. 확정 사항

- 페이지 흐름: 시작 로딩 → 첫 화면 → 디자인 선택 → 커스텀 → 완성 로딩 → 완성 페이지 → 주문 확인 → 주문 완료
- 시작 로딩: 사이트에 처음 들어오면 털실이 소복이 쌓이는 로딩 화면
- 완성 로딩: 방문자가 고른 털실이 뽑히면서 최종 완성본으로 넘어감
- 디자인: 강아지·고양이·토끼·곰·코끼리·호랑이 총 6가지
- 색상: 빨강·분홍·주황·노랑·초록·파랑·남색·검정·회색·흰색 총 10가지, 약간 파스텔 톤
- 털실: 부슬부슬한 털실·벨벳형 부드러운 털실·두툼한 털실 총 3가지
- 크기: 10cm / 20cm / 30cm
- 커스텀: 색상·털실·크기를 한 페이지에서 선택
- 디자인 선택: 별도 페이지
- 주문 확인: 별도 페이지
- 첫 화면: 브랜드 인상을 전하는 별도 화면. 브랜드 문구 "한 땀 한 땀, 당신을 위하여", 만드는 순서 안내, 인테리어·실제 사용 예시, 푸터
- 주문 완료: 결제 입력 화면 없이 주문 확인 다음에 바로 완료 화면을 보여줌 (실제 결제 없음)

## 4. 고른 대안과 이유

| 항목 | 고른 대안 | 이유 |
|---|---|---|
| A. 커스텀 단계 구성 | 한 페이지에 색상·털실·크기 섹션 배치 | PC 우선이라 넓은 화면에 미리보기를 띄워 둔 채 선택지를 옆에 둘 수 있음 |
| B. 디자인 선택 위치 | 별도 페이지로 분리 | 디자인을 고르는 일과 꾸미는 일이 나뉘어 흐름이 명확함 |
| C. 주문 확인 방식 | 별도 페이지 | 정보가 나중에 늘어날 때 담기 좋음 |
| D. 첫 화면 | 브랜드 인상을 전하는 별도 첫 화면 | '따뜻하고 포근한 손맛'이라는 인상을 전달하기에 유리함 |
| E. 주문 마무리 | 결제 화면 대신 주문 완료 화면 | 실제 결제가 없으므로 입력 단계를 줄이고 완료 안내로 마무리 |

## 5. 추후 결정

- 첫 화면 대표 이미지
- 첫 화면 인테리어·실제 사용 예시에 쓸 사진
- 첫 화면 푸터에 담을 내용
- 디자인별 색상 선택 3부위 (호랑이 줄무늬, 코끼리 귀·코 처리 포함)
- 크기 10cm / 20cm / 30cm의 기준 (높이·가로·세로 중 무엇인지)
- 크기·털실별 가격 금액
- 제작 기간
- 저장·공유 이후의 다음 행동
- 주문 완료 화면 이후의 다음 행동 (처음으로 돌아가기 등)
- 시작 로딩(털실이 쌓임)과 완성 로딩(고른 털실이 뽑힘)을 이어지는 연출로 할지 여부
