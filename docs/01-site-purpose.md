# 손뜬 스튜디오 — 사이트 목적 정의

## 1. 사이트 목적 한 문장

손뜬 스튜디오는 정해진 인형 디자인에 원하는 색·털실·크기를 골라, 정성 들여 뜬 나만의 인형을 주문하는 수제 커스텀 인형 스튜디오다.

## 2. 주요 방문자와 방문자의 필요

### 방문자
- **주요 방문자**: 내 공간에 둘 나만의 소품을 찾는 20~30대
- **보조 방문자**: 특별한 선물을 찾는 사람

### 방문 환경
- PC 우선
- 모바일은 기본 대응 (작은 화면에서 2단은 1단, 3열 카드는 2열로 바꾸고, 가로 사진 줄은 손가락으로 넘김)

### 방문자의 필요
방문자가 아래 순서대로 고르며 인형을 완성할 수 있어야 한다.

1. **디자인 고르기**: 메뉴에서 인형 디자인을 고른다.
   - 총 6가지: 강아지 / 고양이 / 토끼 / 곰 / 코끼리 / 호랑이
2. **색상 고르기**: 인형마다 정해진 3군데의 색을 고른다. 색을 누르면 인형에 바로 반영되어 임시로 보인다.
   - 선택지 10가지: 빨강 / 분홍 / 주황 / 노랑 / 초록 / 파랑 / 남색 / 검정 / 회색 / 흰색
   - 색감: 완전한 원색이 아닌 약간 파스텔 톤
   - 예시(토끼): ① 전체 바탕색 ② 눈 색 ③ 귀와 발바닥 색
3. **털실 고르기**: 털실을 누르면 털실별 설명이 보인다.
   - 부슬부슬한 털실: 털이 보송한 느낌
   - 벨벳형 부드러운 털실: 가장 기본형
   - 두툼한 털실: 뜨개 모양이 가장 큼
4. **크기 고르기**: 10cm / 20cm / 30cm 중에서 고른다. 크기는 **높이 기준**이다.
5. **최종 이미지 보기**: 모든 선택을 마치면 로딩 화면에서 방문자가 고른 털실이 뽑히면서 최종 완성본으로 넘어간다. 최종 이미지에는 고른 색과 털실 느낌이 모두 반영된다.

## 3. 가장 중요한 행동과 보조적인 행동

### 가장 중요한 행동
- 커스텀을 끝까지 완성한 뒤 주문하기

### 주문 흐름
1. 최종 이미지 확인
2. 주문하기 버튼 → 가격과 제작 기간 안내 (가격은 크기와 털실 종류에 따라 달라짐)
3. 확인 버튼 → 주문 완료 화면 (실제 결제 없이 완료 안내만 보여줌)

### 보조적인 행동
- '5. 기획을 위한 가정' 참고

## 4. 전달하고 싶은 인상과 피하고 싶은 방향

### 전달하고 싶은 인상
- 따뜻하고 포근한 손맛
- 정성이 많이 들어간 수제 스튜디오 느낌

### 브랜드 문구
- "한 땀 한 땀, 소중한 인형을 위하여" — 사이트 전체에서 이 문구로 통일

### 피하고 싶은 방향
- 흔한 공장형 쇼핑몰 느낌
- 유치한 장난감 느낌
- 차갑고 디지털스러운 느낌

## 5. 기획을 위한 가정

> 아래는 확정 사항이 아니라, 기획을 진행하기 위해 세운 가정이다.

- **보조적인 행동**: 완성한 인형을 저장하거나 공유하기
  - 보조 방문자인 '선물을 찾는 사람'이 고민하거나 다른 사람에게 보여주기 좋다고 가정함

## 6. 다음 단계에서 결정할 내용

- **디자인별 색상 선택 3부위**
  - 호랑이는 줄무늬를 어떻게 처리할지 (세 번째 부위를 줄무늬로 할지, 줄무늬 색을 고정할지)
  - 코끼리는 세 번째 부위를 '귀'로 할지 '귀와 코'로 할지
- **가격**: 크기와 털실 종류별 실제 금액
