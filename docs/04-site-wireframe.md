## 범례 (그리는 규칙)

| 요소 | 표현 |
|---|---|
| 텍스트 | 문구 초안 (굵은 글씨 = 제목, 회색 글씨 = 본문). 화면 예시는 '토끼'를 고른 경우 |
| 이미지 | X 상자 (상자 아래 작은 글씨 = 들어갈 이미지 설명) |
| 메뉴·버튼·선택지·입력칸 | 구분할 수 있는 크기의 실제 컨트롤 모양 + 실제 라벨 |
| 핵심 행동 | 주황색 테두리 + '핵심 행동' 태그 |
| ID 태그 | 보라 = 메뉴(M), 초록 = 섹션(S), 파랑 = 버튼(B) |
| 섹션 | 연한 테두리 영역, 화면 안에서 위→아래로 쌓음 |
| 미정 · [가정] | 점선 상자 / 점선 메모 + '추후 결정' 표기 |

## ID 규칙

| 메뉴 | M-번호 | M-01 |

| 버튼 | B페이지번호-순서 (레이어는 BO번호-순서) | B3-2, BO1-3 |

## 페이지별 와이어프레임

### P0 시작 로딩
- 헤더 없음. 로딩이 끝나면 **P1으로 자동 이동**
- **S0-1 로딩 연출**
  - 이미지(X): 털실이 소복이 쌓이는 연출
  - 문구 (가운데): "털실을 한 타래씩 모으고 있어요"
  - 진행 막대

### P1 첫 화면
- GNB 헤더 (M-01, M-02)
- **S1-1 브랜드 인상 영역** (2단)
  - 왼쪽: 이미지(X) 브랜드 대표 이미지 (추후 결정)
  - 오른쪽
    - 제목: "한 코 한 코, / 나만의 인형을 떠 드려요" (두 줄)
    - 본문: "디자인을 고르고 색과 털실, 크기를 정하면 손뜬 스튜디오가 / 정성껏 떠서 보내 드려요."
    - 본문: "내 공간에 오래 두고 아낄, 하나뿐인 인형을 만들어 보세요."
    - 작은 이미지(X) 2개
  - 버튼 **B1-1 나만의 인형 만들기** (핵심 행동) → P2
- **S1-2 만드는 순서 안내**
  - 제목: "이렇게 만들어져요"
  - 단계 4칸 (각각 이미지(X) + 단계명 + 설명 1줄)
    - "01 디자인 고르기" — "여섯 동물 중 하나를 골라요"
    - "02 색상 고르기" — "세 군데 색을 고르면 바로 보여요"
    - "03 털실 고르기" — "보송한 느낌부터 도톰한 느낌까지"
    - "04 크기 고르기" — "10cm · 20cm · 30cm 중에서 골라요"
- **S1-3 인형 인테리어나 실 사용예**
  - 3열 × 2행 카드. 카드 = 이미지(X) + 장면 이름 (페이지 이동 없음)
  - 예시 1 책상 위 / 예시 2 침대 머리맡 / 예시 3 선반 위 / 예시 4 창가 / 예시 5 소파 위 / 예시 6 선물 상자 속
  - 장면 이름은 초안, 실제 사진은 추후 결정
- **푸터** (FOOTER, 높이 190)
  - 내용 추후 결정

### P2 디자인 선택
- GNB 헤더 (M-01, M-02)
- **S2-1 페이지 제목**
  - 제목: "어떤 친구를 떠 드릴까요?"
  - 안내: "디자인을 고르면 색과 털실, 크기를 정하는 단계로 넘어가요."
- **S2-2 디자인 목록**
  - 3열 × 2행 카드 목록. 카드 = 이미지(X) + 디자인 이름, 카드 전체가 버튼
  - B2-1 강아지 / B2-2 고양이 / B2-3 토끼 / B2-4 곰 / B2-5 코끼리 / B2-6 호랑이 → 모두 P3

### P3 커스텀
- GNB 헤더 (M-01, M-02)
- **S3-1 진행 안내** (전체 너비)
  - 제목: "토끼 꾸미기" (고른 디자인 이름 + 꾸미기)
  - 안내: "색 → 털실 → 크기 순서로 골라 주세요. 고른 색은 미리보기에 바로 보여요."
- 본문 2단: 왼쪽에 미리보기(S3-2), 오른쪽에 선택 섹션 S3-3 → S3-4 → S3-5를 위에서 아래로 쌓음
- **S3-2 인형 미리보기** (왼쪽, 너비 520)
  - 이미지(X): 인형 미리보기 (고른 색 즉시 반영)
  - 안내: "털실 느낌은 완성 화면에서 확인할 수 있어요."
- **S3-3 색상 선택** (오른쪽)
  - 부위 탭 3개 (토끼 예시, 01 문서 기준): 전체 바탕 / 눈 / 귀·발바닥
  - 점선 메모: 디자인별 3부위 — 추후 결정 (화면은 토끼 예시)
  - 색상 칩 10개: 빨강 / 분홍 / 주황 / 노랑 / 초록 / 파랑 / 남색 / 검정 / 회색 / 흰색
- **S3-4 털실 선택** (오른쪽)
  - 선택 카드 3개: 부슬부슬한 털실 / 벨벳형 부드러운 털실 / 두툼한 털실
  - 털실 설명 영역 (선택한 털실의 설명. 화면은 부슬부슬한 털실 선택)
    - 제목: "부슬부슬한 털실"
    - 설명: "털이 보송하게 일어나 포근한 느낌을 줘요."
    - 안내: "다른 털실을 누르면 그 털실의 설명으로 바뀌어요."
- **S3-5 크기 선택** (오른쪽)
  - 크기 선택 버튼 3칸: 10cm / 20cm / 30cm
  - 점선 메모: 크기 기준(높이·가로·세로) — 추후 결정
- **S3-6 하단 버튼** (전체 너비)
  - 버튼 B3-1 디자인 다시 고르기 → P2
  - 버튼 **B3-2 완성하기** (핵심 행동) → P4

## Figma에서 정리가 필요한 부분

- **P7 프레임 이름**: Figma에는 'P6 주문 완료'로 되어 있어 P6 주문 확인과 번호가 겹칩니다. 이 문서에서는 P7 주문 완료로 적었습니다.
- **P8 결제 이후 화면**: 결제 화면이 주문 완료로 바뀌면서 이 화면으로 오는 버튼이 없어졌습니다. 주문 완료가 그 역할을 대신하면 삭제를 검토해 주세요.
- **P7 다음 행동**: 주문 완료 화면에 버튼이 없어 흐름이 끝납니다. '처음으로' 같은 버튼이 필요한지 정해야 합니다.
- **P7 완료 안내 영역**: 섹션 틀과 ID 없이 놓여 있습니다. 섹션으로 묶는다면 S7-2로 이어 붙이면 됩니다.
- **완료 문구 띄어쓰기**: "완료 되었습니다" → 맞춤법상 "완료되었습니다"가 맞습니다.
- **사이트맵 프레임**: 사이트맵 Figma 프레임은 아직 '7. 결제 화면'으로 남아 있습니다 ([03-site-map.md](03-site-map.md) 참고).
