| 요소 | 표현 |
|---|---|

### P1 첫 화면
> 2026-11-13 참고 사진(MODOA 홈 오브젝트 메인 페이지)의 레이아웃으로 재구성. 섹션 흐름: 2분할 상단 → 카드 슬라이드 → (만드는 순서 안내) → 3분할 사용 예시 → 푸터

- GNB 헤더 (M-01, M-02) — 로고 왼쪽, 메뉴 가운데. 지금 보고 있는 메뉴는 밑줄로 표시
- **S1-1 브랜드 인상 영역** (2분할, 좌우 두 칸)
  - 왼쪽 칸: 글 영역
    - 제목(브랜드 문구): "한 땀 한 땀, / 소중한 인형을 위하여" (두 줄, 크게)
    - 본문: "디자인을 고르고 색과 털실, 크기를 정하면 손뜬 스튜디오가 / 정성껏 떠서 보내 드려요."
    - 본문: "내 공간에 오래 두고 아낄, 하나뿐인 인형을 만들어 보세요."
    - 버튼 **B1-1 나만의 인형 만들기 →** (핵심 행동) → P2
  - 오른쪽 칸: 이미지(X) 큰 브랜드 대표 이미지 — 공간에 놓인 인형 (추후 결정)
- **S1-2 디자인 둘러보기** (카드 슬라이드, 새로 추가)
  - 윗줄: 왼쪽에 섹션 제목(문구 추후 결정), 오른쪽에 이전·다음 화살표 버튼
  - 디자인 6종 카드를 가로로 놓고 한 화면에 4개씩 보임. 화살표로 넘김
  - 카드 = 이미지(X, 인형 뒤 옅은 바탕) + 디자인 이름 + 작은 이동 버튼. 카드 전체가 버튼
  - B1-2 강아지 / B1-3 고양이 / B1-4 토끼 / B1-5 곰 / B1-6 코끼리 / B1-7 호랑이 → 모두 P3 (그 디자인으로 시작, P2 카드와 같은 동작)
  - 카드 줄 아래: 지금 위치를 보여 주는 진행 막대
- **S1-3 만드는 순서 안내** (사진에 없는 섹션, 기존 내용 유지)
  - 제목: "이렇게 만들어져요"
  - 단계 4칸 (각각 이미지(X) + 단계명 + 설명 1줄)
    - "01 디자인 고르기" — "여섯 동물 중 하나를 골라요"
    - "02 색상 고르기" — "세 군데 색을 고르면 바로 보여요"
    - "03 털실 고르기" — "보송한 느낌부터 도톰한 느낌까지"
    - "04 크기 고르기" — "10cm · 20cm · 30cm 중에서 골라요"
- **S1-4 인형 인테리어나 실 사용예** (3분할)
  - 왼쪽: 이미지(X) 큰 사진 — 지금 보이는 장면
  - 가운데: 제목 + 짧은 글 (문구 추후 결정) + 버튼 B1-8 (라벨 추후 결정) → P2
  - 오른쪽: 이미지(X) 작은 사진 — 다음 장면 + 점 표시(몇 번째 장면인지)
  - 장면 6개 (초안): 책상 위 / 침대 머리맡 / 선반 위 / 창가 / 소파 위 / 선물 상자 속. 실제 사진은 추후 결정
  - 장면을 넘기는 방식(자동 / 직접): 추후 결정. 모바일에서는 손가락으로 넘김
- **푸터** (FOOTER, 높이 190)
  - 내용 추후 결정
- **모바일 (기본 대응)**: S1-1은 글 → 이미지 순서로 1단으로 쌓음. S1-2는 한 화면에 카드 2개, 손가락으로 넘김. S1-4는 큰 사진 → 글·버튼 순서로 쌓고 작은 사진은 숨김
- **디자인 참고 메모** (와이어프레임에는 그리지 않음, 5단계 Claude Design에서 확정): 모서리가 둥근 큰 카드, 글 칸의 옅은 색 바탕, 카드 이미지 뒤 옅은 파스텔 바탕, 화살표가 붙은 알약형 버튼(채운 버튼 / 테두리 버튼), 제목 옆 반짝이 장식, 세리프 계열 큰 제목, 포인트 색 하나로 버튼·제목 강조
