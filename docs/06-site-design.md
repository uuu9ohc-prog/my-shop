## 1. 디자인 방향

- **인상**: 따뜻하고 정성 들어간 수제 스튜디오. 크림색 바탕 위에 핑크·피치 색 블록을 두고, 포인트 색은 레드 하나만 씁니다.
- **모양**: 전부 둥글게. 버튼은 알약 모양, 카드와 이미지는 큰 모서리, 그림자는 쓰지 않습니다.
- **시그니처**: 가장자리가 털실 뭉치처럼 몽글몽글한 사진 틀(뜨개 모양 틀)과 섹션 제목 앞뒤의 ✦ 표시.
- **피할 것** (01 기준): 공장형 쇼핑몰(빽빽한 그리드, 할인 배지), 유치한 장난감(원색, 만화 글꼴), 차갑고 디지털스러운 느낌(회색, 그라데이션, 유리 효과).

### 2-2. 색 사용 규칙

- 레드는 **포인트 색 하나**입니다. 넓은 면을 레드로 칠하지 않고 버튼·제목·작은 표시에만 씁니다.
- 핑크(`pink-200`) 위 레드 글자는 대비가 3.39:1이라 **24px 이상 제목에만** 씁니다.
- 핑크 바탕 위 작은 본문은 `ink-soft`를 씁니다.
- 디자인 카드 이미지 바탕은 동물마다 다르게: 강아지·곰 `pink-200`, 고양이 `sky-200`, 토끼 `peach-200`. 코끼리·호랑이 **[미정]**

### 2-3. 글자 대비 (읽기 기준 4.5:1)

| 글자 / 바탕 | 대비 | 판정 |
|---|---|---|
| `ink` / `surface` | 14.05 : 1 | 통과 |
| `ink-soft` / `surface` | 7.02 : 1 | 통과 |
| `ink-muted` / `surface` | 5.83 : 1 | 통과 |
| `red-500` / `surface` | 4.61 : 1 | 통과 (작은 글자 가능) |
| `on-red` / `red-500` | 4.67 : 1 | 통과 |
| `red-500` / `pink-200` | 3.39 : 1 | 24px 이상 제목만 |
| `ink-faint` / `surface` | 3.77 : 1 | 24px 이상만 |
| `ink-muted` / `pink-200` | 4.29 : 1 | ⚠ 미달 |

⚠ **현재 P1 시안의 S1-1 본문**은 `ink-muted`를 핑크 위에 써서 기준에 못 미칩니다. → `ink-soft`로 바꾸길 권장합니다.

## 10. 아직 정하지 않은 것

- 제목 글꼴 확정 (Pretendard 가정), 보조 글자 세리프 사용 여부
- 로고 원본 파일 (디자인 시스템의 로고 마크는 시안을 보고 다시 그린 임시 모양)
- 뜨개 모양 틀 원본 모양 (지금은 CSS로 다시 그린 근사치)
- 코끼리·호랑이 카드 이미지 바탕색
- P0·P2~P7, OV-01 화면의 디자인 — 아래 요소는 디자인 시스템에 아직 없음
  - P3: 부위 탭, 색상 칩 10색(파스텔 값), 털실 선택 카드, 크기 버튼, 인형 미리보기 영역, 고르지 않은 항목 알림
  - P5·P6·P7: 선택 요약 줄, 가격 표시 색, 제작 기간 표시
  - OV-01: 어두운 배경, 가운데 창
  - P0·P4: 로딩 연출 화면
- 어두운 테마 (지금은 밝은 테마 하나)
- 모바일 화면에서의 글자 크기·여백
