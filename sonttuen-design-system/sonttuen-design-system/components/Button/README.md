# Button

알약 모양 버튼 두 가지: 화면의 핵심 행동 하나에만 쓰는 **Primary**(레드 채움)와 그 밖의 행동에 쓰는 **Outline**(레드 외곽선)입니다.

## 쓰는 법

- **Primary** `ss-btn ss-btn--primary` — 한 화면에 한 번만. "나만의 인형 만들기"처럼 커스텀을 시작하는 행동. 높이 `control-lg`(60px), 배경 `red-500`, 글자 `on-red`, 오른쪽에 반투명 흰 원 안 화살표.
- **Outline** `ss-btn ss-btn--outline` — 보조 행동. 높이 `control-md`(56px), 1.5px `red-500` 테두리, 오버 시 채워짐.
- 모서리는 항상 `radius-pill`. 각진 버튼은 쓰지 않습니다.
- 문구는 동사로 끝나는 짧은 말: "만들기", "보러 가기". 느낌표 쓰지 않기.
- 화살표 아이콘은 사용하는 쪽에서 넣습니다(24px 선 아이콘, 2px 선).
- 오버 색 `red-600`은 시안에 없던 제안값입니다.
