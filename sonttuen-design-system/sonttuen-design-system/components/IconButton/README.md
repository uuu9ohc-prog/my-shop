# IconButton

아이콘만 있는 원형 버튼: 외곽선(헤더 메뉴·캐러셀 화살표), 레드 작은 원(카드 화살표), 테두리 없는 헤더 아이콘 세 가지입니다.

- **외곽선** `ss-icon-btn` — 52px, 1.5px `ink` 테두리. 더 갈 곳이 없으면 `disabled` → `control-off` 색.
- **레드** `ss-icon-btn--red` — 40px, `red-500` 채움. 카드 안에서 "자세히 보기"를 뜻함.
- **플레인** `ss-icon-btn--plain` — 헤더의 검색·찜·장바구니. 오버 시 `pink-100` 바탕.
- 아이콘만 있으므로 `aria-label`은 꼭 넣을 것.
