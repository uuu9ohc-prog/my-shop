# 손뜬 스튜디오 — 디자인 시스템

손뜬 스튜디오는 디자인을 고르고 색·털실·크기를 정하면 한 땀씩 떠서 보내 주는 **커스텀 니트 인형 브랜드**입니다. 사이트는 쇼핑몰이 아니라 인형 하나를 정성껏 소개하고 "나만의 인형 만들기"로 이끄는 브랜드 사이트입니다. 이 시스템은 P1 메인 화면 시안(1440px)을 기준으로 정리했습니다.

## 브랜드 인상

- **따뜻하고 정성 들어간 수제 스튜디오.** 크림 바탕 위에 핑크·피치 블록, 포인트는 레드 하나.
- 피할 것: 공장형 쇼핑몰(빽빽한 상품 그리드, 할인 배지), 유치한 장난감(원색, 만화 글꼴), 차갑고 디지털스러운 느낌(회색, 그라데이션, 유리 효과).

## 말투

- 짧고 다정한 "~해요 / ~보세요" 체. 예: "세 군데 색을 고르면 바로 보여요", "하나뿐인 인형을 만들어 보세요."
- 느낌표, 이모지, "최저가·특가" 같은 판매 문구는 쓰지 않습니다.
- 버튼은 동사로: "나만의 인형 만들기". 숫자 단계는 `01 디자인 고르기`처럼 두 자리.

## 색

| 역할 | 토큰 | 쓰는 곳 |
| --- | --- | --- |
| 바탕 | `surface` #fffef3 | 페이지 전체(크림) |
| 카드 | `surface-card` #fffaf6 | 디자인 카드 |
| 포인트 | `red-500` #bc2010 | 로고, 제목, 주요 버튼, 화살표, 진행 바 |
| 블록 | `pink-200` `pink-100` `peach-200` `sky-200` | 히어로·푸터·이미지 자리. 동물별로 색을 나눠 씀 |
| 글자 | `ink` → `ink-soft` → `ink-muted` → `ink-faint` | 진한 순서. `ink-faint`는 24px 이상만 |
| 선 | `line`, `line-dashed`, `dot-off` | 구분선·카드 테두리, 기획 메모 칩, 꺼진 점 |

규칙
- 레드는 **포인트 한 색**입니다. 넓은 면을 레드로 칠하지 않고, 버튼·제목·작은 표시에만.
- 핑크 블록(`pink-200`) 위 레드 글자는 4.55:1로 기준 통과. 핑크 위 본문은 `ink-soft`.
- ⚠ 현재 시안의 히어로 본문은 `ink-muted`를 핑크 위에 써서 4.29:1로 기준 미달입니다 → `ink-soft`로 바꾸길 권장.

## 글자

- 글꼴: **Pretendard** (없으면 Noto Sans KR). 제목은 같은 글꼴을 900 굵기로.
- ⚠ 시안 제목 글꼴은 화면으로만 확인했습니다. 별도 제목용 글꼴을 쓰고 있다면 `type.families.display`를 바꾸고 글꼴 파일을 `fonts/`에 넣어 주세요.
- 크기: 히어로 56 · 섹션 제목 40 · 소제목 36 · 카드 이름 20 · 단계 제목 18 · 본문 17/16 · 버튼 15 · 캡션 13 (px).
- 제목은 자간 -2%, 본문은 줄간격 1.6~1.75로 넉넉하게.

## 모양과 간격

- **둥글게.** 버튼·칩은 전부 알약(`radius-pill`), 카드 `radius-md` 20px, 이미지 `radius-sm` 16px, 큰 색 블록 `radius-lg` 28px.
- **뜨개 모양 틀(KnitFrame)** 은 이 브랜드의 시그니처. 털실 뭉치처럼 가장자리가 몽글몽글한 사진 틀로, 한 화면에 한두 번만 씁니다.
- 그림자 없음. 깊이는 색 블록과 1px `line` 테두리로만.
- 콘텐츠 폭 1200px, 좌우 여백 120px, 카드 간격 24px, 섹션 위아래 80px + 1px 구분선.

## 아이콘

- 24px 선 아이콘, 선 굵기 1.8~2px, 끝 둥글게. 색은 글자색을 따라감.
- 화살표(→)는 "다음으로·자세히"를 뜻하며 버튼 안 원 속에 넣습니다.
- 털실 뭉치 아이콘은 "인형 사진이 들어갈 자리"를 뜻합니다.
- ⚠ 로고 원본 파일이 없어 컴포넌트 미리보기의 로고 마크는 시안을 보고 다시 그린 임시 모양입니다. 실제 로고 SVG를 받으면 Logos 자산으로 올려 교체하세요.

## 컴포넌트

Button · IconButton · SectionTitle · Note · Placeholder · KnitFrame · DesignCard · StepCard · Progress · Header · Footer

- 모두 CSS 클래스(`ss-` 접두사)로 만들어져 있어 React 없이 HTML에 그대로 쓸 수 있습니다. 스타일은 `components/bundle.css`, 값은 `tokens.css` 변수를 씁니다.
- React(Vite) 프로젝트에서는 `tokens.css`와 `bundle.css`를 전역으로 불러온 뒤 같은 클래스 이름을 쓰면 됩니다.
- **Note(점선 메모 칩)** 는 기획 단계 표시용입니다. 공개 전에 모두 실제 문구로 바꾸세요.

## 아직 정해지지 않은 것

- 로고 원본, 제목 글꼴 확정, 푸터 내용, "제목 자리"·"버튼 라벨" 문구.
- 어두운 테마(지금은 밝은 테마 하나).
- 커스텀 화면(색·털실·크기 선택), 털실 뽑기 로딩, 주문·결제 화면의 컴포넌트 — 해당 시안이 나오면 추가.
